# ispacecraft

작은 우주선에서 시작하는 항해. 선내를 걷고, 직접 조종하고, 낯선 천체를 탐사하며 다음 여정을 준비합니다.

**개발 중인 브라우저 기반 3D 우주 프로젝트** ispacecraft의 공개 소개 문서입니다. 기획·디자인·개발·우주선 공학·과학·세계관을 분야별로 읽을 수 있습니다. 앱 소스와 내부 개발 자료는 별도 비공개 저장소에서 관리합니다.

[브라우저에서 열기](https://ispacecraft.com) · [프로젝트 소개](docs/overview.md) · [현재 범위](docs/status.md) · [HTML 시작 파일](index.html)

## 우주선 한 척, 이어지는 선택

목적지를 고르고 항해합니다. 선외로 나가거나 표면에 내려 자원을 모읍니다. 우주 광석을 연료와 생명 유지에 쓰고, 남은 물자를 정거장에서 거래하며 배를 정비합니다. 얼마나 더 나아갈지와 언제 돌아올지를 함께 판단합니다.
