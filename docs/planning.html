기획 — 항해를 이어 가는 선택

현재 구현의 중심은 이동·탐사·채굴·생존·귀환의 연결입니다. 자원을 얻는 행동과 그 자원을 쓰는 행동이 다음 항해의 범위를 바꿉니다.

기본 순환

  1. 산소와 연료, 창고의 여유를 확인합니다.
  2. 목적지를 고르고 수동 조종이나 AI 항법으로 이동합니다.
  3. 주변 지형과 위험을 살펴 착륙하거나 선외 활동을 시작합니다.
  4. 광석·물을 채집하고 우주선으로 회수합니다.
  5. 필요한 광석을 생존 물자와 연료로 전환합니다.
  6. 정거장에서 남은 광석을 팔고 보급·정비·업그레이드를 합니다.
  7. 준비 상태에 맞춰 다음 목적지를 정합니다.

같은 광석, 서로 다른 용도

우주 광석은 이동과 생존에 쓰이면서 거래할 수도 있는 자원입니다. 더 먼 곳까지 가기 위해 연료로 쓸지, 현재 부족한 산소를 만들지, 정거장에 가져가 팔지 선택합니다. 수익만 늘리는 경로가 안전한 항로와 항상 같지는 않습니다.

위험은 서로 연결됩니다

상황판단할 것
오래 머무는 선외 활동남은 산소, 피폭, 우주선까지의 귀환 거리
행성 착륙지형·경사, 대기 진입, 제동과 이륙에 필요한 능력
채굴 지속광상의 잔량, 전력, 창고 용량, 귀환 물자
정거장으로 이동남은 연료와 접근·제동 여유

캠페인으로 달라지는 과제

첫 항해 가이드는 조작과 채굴·거래를 연결합니다. 태양계 캠페인은 천체 간 이동과 탐사에, 함대전 계열은 탈출·구조·고물 회수처럼 특정 상황의 목표에 초점을 둡니다. 캠페인 판은 일반 세계 저장과 구별되며 종료 시 기록과 보상을 정산합니다.

장기 기획

연합·평판·외계 문명은 장기 구상입니다. 도킹 상대를 신뢰할지, 자원을 함께 사용할지, 다른 환경에서 온 여행자와 어떻게 만날지 탐색하는 방향입니다. 이러한 설정이 현재 P2P 협동에 모두 구현된 것은 아닙니다.
