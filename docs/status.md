# 현재 범위와 FAQ

기준일: **2026-11-02**. 내부 개발 문서 기준의 설명이며 운영 배포의 기능·버전과 다를 수 있습니다. 향후 일정이나 성능 수치를 보장하지 않습니다.

## 상태 구분

| 표기 | 의미 |
|---|---|
| 현재 | 개발 문서에서 구현을 확인한 범위 |
| 계획 | 추진 방향이 정해졌지만 구현 전인 범위 |
| 구상·제안 | 상세 설계나 승인·검증이 더 필요한 내용 |

## 모든 참가자가 자원을 공유하나요?

현재 P2P는 모든 세계 상태를 하나로 맞추는 구조가 아닙니다. 광상 채굴과 정거장 거래 같은 변경은 기기별 차이가 생길 수 있습니다. 완전한 공동 경제나 서버가 검증하는 자원 공유를 제공한다고 해석하지 않아야 합니다.

## 저장은 클라우드 계정에 보관되나요?

현재 기기·브라우저에 보관합니다. 공유 창고 역시 기기 내 데이터이며, 이름에 ‘공유’가 있어도 다른 기기의 계정 클라우드 저장을 뜻하지 않습니다. 세계 내보내기에는 별도 창고·캠페인 기록이 모두 포함되지 않습니다.

## 과학 수치는 모두 현실과 같나요?

관성과 중력 등에서 실제 원리를 참고하지만 거리·시간·자원·피폭·장치에는 근사와 허구가 있습니다. [과학 문서](science.md)에서 구분을 설명합니다.

## 소스코드를 받을 수 있나요?

이 저장소는 공개 소개 문서용입니다. 앱 소스와 원본 개발 자료는 별도 비공개 저장소에서 관리합니다. 문서의 공개가 앱 코드나 자료의 오픈소스 전환을 뜻하지 않습니다.

## HTML은 어디서 읽나요?

저장소의 index.html을 브라우저로 열면 문서 전체를 탐색할 수 있습니다. GitHub의 파일 화면은 HTML 소스 보기이며 실제 페이지 호스팅과 다릅니다. 이 저장소를 만들었다고 GitHub Pages가 자동 활성화되지는 않습니다.
