# 과학 — 실제 원리와 프로젝트의 근사

ispacecraft는 관성·중력·궤도·대기 진입 같은 현상을 다룹니다. 이 문서는 실제 원리와 프로젝트 규칙의 경계를 설명합니다. 현재 구현 전체가 현실의 우주 비행을 정밀하게 재현하는 것은 아닙니다.

## 이동과 궤도

관성 비행에서는 추력을 멈춰도 속도가 즉시 없어지지 않습니다. 정지하려면 반대 방향의 추력이 필요하며 연료가 듭니다. 도움 기능의 보조 비행은 이 역분사를 자동으로 수행합니다.

이상적인 구형 중심 천체와 원궤도를 가정하면 공전 속도는 v = √(μ/r), 탈출 속도는 vₑ = √(2μ/r)로 표현합니다. μ는 중심 천체의 중력 매개변수, r은 중심까지의 거리입니다. 이 식은 대기·다체 섭동·추력 손실 등을 모두 포함한 비행 해답은 아닙니다.

표면 중력은 이동과 이착륙에 영향을 줍니다. 선내 인공 중력은 프로젝트가 도입한 별도 규칙이며, 실제 우주선에서 임의의 중력을 만드는 기술이 확립됐다는 뜻은 아닙니다.

## 대기 진입

대기 속의 빠른 이동에는 저항과 가열이 생깁니다. 진입 각도와 속도, 대기 밀도에 따라 위험이 달라집니다. 프로젝트는 이를 비행 판단에 연결하지만, 유동·열전달·재료 파손을 모두 푸는 공학 해석은 수행하지 않습니다.

## 진공에서의 채굴

진공에는 지상의 연기처럼 주변 공기를 타고 번지는 흐름이 없습니다. 날아가는 파편은 초기 속도와 주변의 힘에 따라 움직입니다. 프로젝트의 절삭 불꽃과 냉각 색 변화는 이 특징을 참고한 시각 효과이며, 실제 광물별 온도·분광을 계산한 결과는 아닙니다.

## 실제와 다른 부분

| 요소 | 구분 |
|---|---|
| 우주 광석에서 연료·산소·식량·물을 추출 | 세계관의 허구적 자원 규칙 |
| AI 칩을 통한 광석 추출물 에너지 이용 | 세계관 설정 |
| 선내 인공 중력 조절 | 시뮬레이션 규칙과 설정 |
| 방사선 축적·회복·피해 | 생존을 위한 단순화된 모델 |
| 거리·속도·시간 배속 | 선택한 우주 설정과 조작에 따른 값 |
| 착륙 장치와 지면 접촉 | 충돌·고정·시각 연출의 근사 |

우주의 ‘실제 / 가상’ 설정은 거리·크기·속도 표현의 구분입니다. ‘실제’를 선택해도 모든 현상이 정밀한 현실 모델로 바뀌지는 않습니다. 프로젝트 속 광년이나 시간 수치를 실제 단위와 혼용하지 않아야 합니다.

## 다음에 탐구할 현상

항성 조명, 천체 외관과 지형, 블랙홀의 렌즈 효과, 실제 위성·탐사선의 위치와 궤적은 향후 확장 방향입니다. 블랙홀의 사건의 지평선과 관측되는 그림자를 구분하고, 실제 궤적 자료에는 기준 시각·좌표계·유효 기간을 붙이는 접근을 검토합니다.
