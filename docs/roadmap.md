# 로드맵 — 우주 표현과 탐사의 확장

기준일: 2026-11-02. 다음은 향후 방향이며 출시 일정은 정해지지 않았습니다. 세부 구현 순서·데이터 공급 경로·기술 선택·임무 구성은 제안 단계가 포함됩니다.

## 현재 기반

3D 브라우저 환경에서 선내·선외 이동, 비행·항법, 탐사·채굴·거래, 저장, 캠페인과 P2P 협동을 연결하고 있습니다. 기존 항해 경험을 유지하면서 천체와 장비의 표현을 발전시킵니다.

## 추진 방향 — 구현 전

| 방향 | 목표 |
|---|---|
| 태양과 행성 | 실제 외관에 가까운 표현을 우선 개선하고 이후 약한 카툰 쉐이딩 검토 |
| 광원 | 항성의 빛, 밝기·가림, 대기와 재질 반응 개선 |
| 지형·지물 | 궤도에서 도보까지 이어지는 지형과 근거리 디테일 |
| 별과 성계 | 고유 위치·정체성을 가진 탐색·방문 대상으로 연결 |
| 블랙홀 | 렌즈 효과와 접근 위험을 가진 천체 표현 |
| 위성·탐사선 | 실존 임무의 대상·궤적·정보를 태양계 탐사에 연결 |
| 지구 궤도 캠페인 | 약 16,000개 규모를 목표로 하는 인공위성 표현 |

위성의 목표 규모는 실시간 실제 위성 수에 대한 통계가 아닙니다. 최종 등장 수는 채택한 데이터와 기준 시각·대상 정의에 따라 정해야 합니다. 실제 궤적 연동과 대규모 캠페인은 아직 구현되지 않았습니다.

## 상세 설계 제안

먼 천체는 간단히, 가까운 대상은 자세히 표현하고 필요한 구역만 생성·유지하는 방식을 검토합니다. 같은 천체를 지도·선택·추적·도착 위치가 일관되게 가리키고 저장 후에도 정체성이 유지되는 것이 기준입니다.

블랙홀은 먼저 단순한 근사 모델을 검증한 뒤 표현을 확장합니다. 위성·탐사선은 소수의 대표 대상에서 위치·시간·추적을 검증한 후 목록을 늘리는 접근을 검토합니다. 관측·접근·귀환 임무의 구체적인 구성은 제안입니다.

## 장기 구상

연합, 평판, 안드로이드 동료, 외계 문명과 지속 온라인 우주는 더 먼 구상입니다. 현재 P2P 협동의 한계를 해소하고 공유 세계를 어떻게 운영할지는 별도의 설계와 검증이 필요합니다.
