# 디자인 — 우주를 보고, 상태를 읽고, 행동하기

화면은 우주를 관찰하는 공간과 조작·정보 영역의 역할을 나눕니다. 상태를 읽고 다음 행동을 찾기 쉽게 만들면서 가운데 3D 장면의 시야를 확보합니다.

## 화면의 역할

| 영역 | 역할 |
|---|---|
| 위쪽 상태창 | 산소·몸·연료와 현재 상태, 발생한 알림 |
| AI 패드 | 생존·우주선·가방·자원·미디어와 상황별 제안 |
| 네비게이션 | 목적지, 운항 상태, 지도와 시간·속도 제어 |
| 아래 매직 버튼 | 현재 상황에서 실행할 행동과 조작 |
| 조종 계기판 | 조종 중 상세 비행 정보 |
| 가운데 장면 | 우주선·천체·지형을 직접 관찰하는 시야 |

AI 패드는 앱 탐색 레일을 가진 세로형 구성을 기준으로 정보를 모읍니다. 네비게이션은 별도로 유지합니다. 초기 좌우 기둥 패널이나 동심원 게이지 시안은 현재 기준으로 소개하지 않습니다.

## 상태와 행동의 연결

알림은 이미 일어난 일을, AI 제안은 지금 할 수 있는 일을 알려 줍니다. 조종석에 앉아야 하는 행동은 자리와 조건을 확인하고, 실행할 수 없는 경우 이유를 보여 주는 방향으로 구성합니다.

목적지 설정은 항로 초안을 바꾸는 동작입니다. AI 운항 시작은 네비게이션에서 실행하며, 행성·소행성에는 착륙, 정거장에는 도킹처럼 대상에 맞는 행동을 연결합니다.

## 도움 기능

보조 비행, 자동 관리, 계기판 숨기기, 매직 버튼 AI 추천을 각각 켜고 끕니다. 훈련생과 조종사는 이 스위치들의 프리셋입니다. 세계가 서로 다른 모드로 갈라지는 방식은 아닙니다. 도움 기능을 바꿔도 생존 수치 자체는 같으며, 보조 비행의 역분사에는 연료가 듭니다.

## 시각 언어

짙은 남청색 바탕에 흰색·회색·청색 계열을 사용합니다. 주황·노랑은 경고, 빨강은 위험을 구분하는 역할입니다. 가는 선 아이콘과 일관된 글자·간격을 사용하고, 데스크톱과 좁은 터치 화면에서 같은 정보의 우선순위를 유지합니다.

태양과 행성은 실사감을 점차 높이고 이후 약한 카툰 쉐이딩을 검토하는 방향입니다. 이 시각 개선은 [향후 계획](roadmap.md)이며 현재 완성 수준을 뜻하지 않습니다. 이 공개 문서의 HTML은 같은 색상 계열을 활용한 독서용 문서입니다.
