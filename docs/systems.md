# 자원과 생존

우주선의 이동과 몸의 생존은 서로 다른 상태를 사용하지만 같은 항해 안에서 연결됩니다. 숫자의 크기뿐 아니라 남은 시간과 귀환 가능성을 함께 읽는 것이 중요합니다.

## 자원의 역할

| 자원·상태 | 역할 |
|---|---|
| 우주 광석 | 연료·산소·식량·물 전환과 거래의 원천 |
| 연료 | 추진과 우주선 장치 운영 |
| 산소 | 선내와 우주복의 생명 유지 |
| 물 | 생명 유지와 탈수 상태 |
| 식량·활력 | 몸의 에너지와 활동 상태 |
| 체력 | 충격·환경 피해와 회복 |
| 피폭 | 선외 활동의 누적 위험 |
| 선체 상태 | 충돌과 진입 등에서 우주선을 보호하는 상태 |

우주 광석은 프로젝트의 허구적 자원입니다. 실제 광물을 같은 방식으로 식량이나 산소로 전환할 수 있다는 설명은 아닙니다.

## 채집에서 재고까지

채굴 장비가 광상을 절삭하고 회수하면 광석을 적재합니다. 창고가 가득 차거나 광상이 고갈되거나 필요한 전력이 부족하면 작업이 제한됩니다. 이미 회수한 광석과 아직 원천에 남아 있는 광석은 구분합니다.

물은 행성 탐사와 보급의 일부로 확보합니다. 정거장은 광석 판매와 물자 구매·수리·업그레이드를 연결하는 거점입니다. 구체적인 비용과 생산량은 개발 중 조정됩니다.

## 자동 관리의 의미

자동 관리는 헬멧·안전줄·광석 전환 등 반복되는 관리 동작을 돕습니다. 자원을 무한히 만들거나 생존 규칙을 없애는 기능은 아닙니다. 탱크·창고·연료의 여유는 계속 확인해야 합니다.

## 귀환을 위한 여유

출발 전에 현재 자원과 가까운 정거장, 목적지의 위험을 확인합니다. 멀리 이동한 뒤 돌아올 연료가 있는지, 선외 작업을 마칠 산소가 남는지, 착륙 후 다시 떠날 추력이 충분한지가 이어지는 판단입니다.
