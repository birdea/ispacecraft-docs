공개 문서 편집 기준

이 저장소는 ispacecraft를 소개하는 공개 자료입니다. 앱 소스와 내부 개발 기록을 관리하는 저장소는 비공개로 유지합니다.

정보의 기준

공개 내용은 내부의 현재 범위, 기획, 승인된 설계와 결정 기록을 재구성했습니다. 과거 결정이 최신 결정과 다르면 최신 내용을 우선합니다. 초안과 목업은 선택·구현된 결과와 구별하고, 로컬 개발 상태를 운영 배포의 상태로 단정하지 않습니다.

초판은 2026-11-02 기준입니다. ‘우주 광석’은 같은 날 오너가 확인한 명칭을 반영했습니다. 최종 제품 목적이나 확정되지 않은 출시 일정은 정의하지 않고 현재 할 수 있는 경험을 설명합니다.

공개 범위

  • 프로젝트 소개와 현재 경험, 기획의 의도.
  • 화면 디자인과 상호작용 원칙.
  • 개발 구조와 검증 방식의 개요.
  • 장비 동작, 과학적 근사와 세계관의 구분.
  • 현재 상태와 향후 계획, 용어 설명.

앱 소스, 관리자 운영·인증 설정, 인프라 식별자, 내부 보안 리뷰, 비공개 자산과 원본 목업은 이 저장소의 공개 대상에 포함하지 않습니다. 내부 문서의 링크와 작업 환경 경로를 외부 독자가 따라야 하는 구조로 만들지 않습니다.

유지보수

내용 원본은 README.md와 docs 폴더의 Markdown입니다. Python 3 표준 라이브러리만 사용하는 scripts/build.py로 같은 내용의 HTML을 생성합니다. 본문은 Markdown에서 수정하고 HTML을 다시 생성해 함께 커밋합니다. 생성된 HTML을 직접 고치면 다음 생성에서 덮어씁니다.

생성 명령은 python3 scripts/build.py, 확인 명령은 python3 scripts/check.py입니다. 확인은 HTML 재현성, 로컬 링크·문서 짝과 공개 범위에 맞지 않는 흔한 문자열을 검사합니다. 자동 검사는 사람의 내용 검토를 대체하지 않습니다.

호스팅과 권리

HTML은 외부 스크립트·분석 도구·폰트 요청 없이 로컬에서 읽을 수 있는 정적 문서입니다. index.html부터 시작하며 같은 폴더 구조를 유지하면 정적 호스팅에서도 동작합니다. 별도 호스팅 설정과 공개 주소 연결은 이 문서 작성과 구별됩니다.
