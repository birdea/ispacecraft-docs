첫 항해 안내

ispacecraft 열기에서 시작합니다. 아래 안내는 개발 문서 기준이며 실제 화면과 키 배치는 배포 버전·사용자 설정에 따라 달라질 수 있습니다. 앱의 도움말과 설정을 기준으로 확인하세요.

처음 시작하기

  1. 처음 실행하면 도움 기능 프리셋을 선택합니다. 익숙하지 않다면 훈련생으로 시작하고 설정에서 개별 도움을 조절합니다.
  2. 첫 항해 가이드나 튜토리얼을 통해 선내 이동과 조종석 이용을 익힙니다.
  3. 위쪽 상태창에서 산소·몸·연료를, AI 패드에서 현재 제안을 확인합니다.
  4. 네비게이션에서 가까운 대상을 선택하고 목적지와 행동을 확인합니다.
  5. 채굴과 회수를 경험한 뒤 정거장으로 돌아와 거래·보급합니다.
  6. 수동 저장하고 다시 불러와 진행이 유지되는지 확인합니다.

조작을 익히는 순서

걷기·우주 유영·조종은 같은 키라도 맥락이 달라집니다. 먼저 이동과 시선, 상호작용을 익히고 조종석에서 분사·회전·정지를 확인하세요. 키 지도는 물음표 키, 메뉴는 Esc에서 확인할 수 있습니다. 터치는 화면의 스틱과 행동 버튼 안내를 따릅니다.

관성 비행에서는 키를 놓아도 움직임이 계속됩니다. 보조 비행을 켜면 자동으로 역분사하지만 연료가 필요합니다. AI 운항도 연료와 도착 조건의 영향을 받습니다.

저장과 기기

진행과 설정은 현재 기기·브라우저에 저장됩니다. 다른 기기에 자동 동기화되지 않습니다. 세계 저장 파일을 내보내고 가져올 수 있지만, 별도로 보관하는 공유 창고와 캠페인 기록까지 모두 포함하는 전체 백업은 아닙니다.

같은 사이트에서 실행하는 게임 탭은 하나입니다. 이미 실행 중이라는 안내가 나오면 기존 탭을 닫고 새로고침합니다. WebGL과 Web Locks를 지원하는 브라우저가 필요합니다. 모든 모바일 기기에서 동일한 성능을 보장하지 않습니다.

같이 하기

메뉴의 같이 하기에서 방을 열거나 방 코드로 참가합니다. 방장의 승인을 받아 연결하며 연결 가능 여부는 네트워크 환경에 영향을 받습니다. 현재 협동은 위치·우주선 상태를 함께 보는 범위가 중심이며, 광상 고갈·정거장 거래 등 세계의 모든 변경이 공유되는 지속 온라인 우주는 아닙니다.
